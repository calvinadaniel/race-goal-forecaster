# Race Goal Forecaster — Design Spec (direction drafts)

## Product
Race Goal Forecaster: Strava-connected race finish-time forecaster. User sets distance, target time, race date, training posture → gets On track / At risk / Unlikely + scenario compare.

## Audience & scene
Serious recreational runners (half/marathon). Desktop + mobile. First impression is the marketing landing; visual system must extend to `/app` forecast.

## Core message
“Will you hit your race goal?” — honest, effort-based forecast — Connect with Strava CTA.

## Emotional tone
Premium athletic confidence (Peloton energy) + coaching clarity (Runna). Not fluffy wellness; not dashboard chrome.

## Locked palette (do not invent new brand hues)
- Sand bg `#F7F3EB` / surface `#EFE8DC`
- Pine ink `#1C2A22` / pine green `#3F6B4F`
- Terracotta accent `#C45C26`
Dark directions: deepen pine to near-black `#0F1713` / `#1C2A22`, sand for type, terracotta for CTA only.

## Format
Landing page desktop mockup **1440×900** screenshot. Single-file HTML. Show: nav, hero, how-it-works, verdict preview card, CTA, disclaimer.

## Assumptions (user said “you pick”)
1. Scope: landing as primary redesign surface; include a forecast “verdict card” so app language is visible.
2. Mode: one dark Peloton-leaning, one light Runna-leaning, one roulette Dark Editorial — all on locked palette.
3. References: Peloton cinematic dark + single accent CTA; Runna goal/verdict clarity cards.

## Visual motif
The **race-day clock / finish time** as hero number — the product’s unique motif (not generic fitness stats).
