# Sans-serif font packages — Race Goal Forecaster

## Assumptions (iteration on Direction 3)
- Layout / palette stay Runna clarity (sand / pine / terracotta).
- User asked for an all-sans package — no serif display.
- Keep a mono for finish times / data (race-clock motif).
- Avoid Inter / Space Grotesk / Fraunces as display.
- Format: type specimens on the landing hero snippet, 1440×900.

## Content type
Marketing landing + product UI (verdict card, times). Scale: ~1.25 for UI, display hero free.

## Three packages

| ID | Logic | Display | Body / UI | Mono | Why |
|----|-------|---------|-----------|------|-----|
| A | Roulette (Schibsted lineage) | Schibsted Grotesk | IBM Plex Sans | IBM Plex Mono | News-bred grotesque; athletic without crypto-tech cliché |
| B | Benchmark (coaching apps) | Plus Jakarta Sans | Figtree | JetBrains Mono | Runna-adjacent clarity; soft geometric UI |
| C | Designer custom | Bricolage Grotesque | Manrope | IBM Plex Mono | Ink traps at large sizes = finish-time signature |
